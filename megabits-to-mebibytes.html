How it works

To convert megabits to mebibytes, multiply the number of megabits by 0.11920929. To convert mebibytes to megabits, multiply by 8.388608 (or divide by 0.11920929). Type a value in either box and the other updates, so this one page works in both directions.

Megabits to Mebibytes formula

Mebibytes = megabits × 0.11920929

Worked example: convert 12.5 megabits to mebibytes. Multiply 12.5 × 0.11920929 = 1.4901161 MiB. To go the other way, multiply mebibytes by 8.388608 (or divide by 0.11920929).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
