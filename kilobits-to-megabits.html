How it works

To convert kilobits to megabits, multiply the number of kilobits by 0.001. To convert megabits to kilobits, multiply by 1,000 (or divide by 0.001). Type a value in either box and the other updates, so this one page works in both directions.

Kilobits to Megabits formula

Megabits = kilobits × 0.001

Worked example: convert 12.5 kilobits to megabits. Multiply 12.5 × 0.001 = 0.0125 Mb. To go the other way, multiply megabits by 1,000 (or divide by 0.001).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
