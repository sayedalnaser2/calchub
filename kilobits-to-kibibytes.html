How it works

To convert kilobits to kibibytes, multiply the number of kilobits by 0.12207031. To convert kibibytes to kilobits, multiply by 8.192 (or divide by 0.12207031). Type a value in either box and the other updates, so this one page works in both directions.

Kilobits to Kibibytes formula

Kibibytes = kilobits × 0.12207031

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
