How it works

To convert kilobytes to megabytes, multiply the number of kilobytes by 0.001. To convert megabytes to kilobytes, multiply by 1,000 (or divide by 0.001). Type a value in either box and the other updates, so this one page works in both directions.

Kilobytes to Megabytes formula

Megabytes = kilobytes × 0.001

Worked example: convert 12.5 kilobytes to megabytes. Multiply 12.5 × 0.001 = 0.0125 MB. To go the other way, multiply megabytes by 1,000 (or divide by 0.001).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
