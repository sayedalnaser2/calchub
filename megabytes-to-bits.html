Convert megabytes to bits and bits to megabytes instantly. 1 MB = 8,000,000 bits.

How it works

To convert megabytes to bits, multiply the number of megabytes by 8,000,000. To convert bits to megabytes, multiply by 1.25e-07 (or divide by 8,000,000). Type a value in either box and the other updates, so this one page works in both directions.

Megabytes to Bits formula

Bits = megabytes × 8,000,000

Worked example: convert 12.5 megabytes to bits. Multiply 12.5 × 8,000,000 = 100,000,000 bits. To go the other way, multiply bits by 1.25e-07 (or divide by 8,000,000).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.

There are 1.25e-07 megabytes in one bit.
