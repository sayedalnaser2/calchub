Gigabytes to Bytes Converter

Convert gigabytes to bytes instantly. 1 GB = 1,000,000,000 B.

How it works

To convert gigabytes to bytes, multiply the number of gigabytes by 1,000,000,000. One gigabyte equals 1,000,000,000 bytes, and one byte equals 1e-09 gigabytes. The table shows common values.

Gigabytes to Bytes formula

Bytes = gigabytes × 1,000,000,000

Worked example: convert 12.5 gigabytes to bytes. Multiply 12.5 × 1,000,000,000 = 12,500,000,000 B. To go the other way, multiply bytes by 1e-09 (or divide by 1,000,000,000).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
