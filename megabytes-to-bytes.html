Megabytes to Bytes Converter

Convert megabytes to bytes instantly. 1 MB = 1e+06 B.

How it works

To convert megabytes to bytes, multiply the number of megabytes by 1e+06. One megabyte equals 1e+06 bytes, and one byte equals 1e-06 megabytes. The table shows common values.

Megabytes to Bytes formula

Bytes = megabytes × 1e+06

Worked example: convert 12.5 megabytes to bytes. Multiply 12.5 × 1e+06 = 1.25e+07 B. To go the other way, multiply bytes by 1e-06 (or divide by 1e+06).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
