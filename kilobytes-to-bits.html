How it works

To convert kilobytes to bits, multiply the number of kilobytes by 8,000. To convert bits to kilobytes, multiply by 0.000125 (or divide by 8,000). Type a value in either box and the other updates, so this one page works in both directions.

Kilobytes to Bits formula

Bits = kilobytes × 8,000

Worked example: convert 12.5 kilobytes to bits. Multiply 12.5 × 8,000 = 100,000 bits. To go the other way, multiply bits by 0.000125 (or divide by 8,000).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
