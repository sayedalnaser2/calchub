Percent Error Calculator

Compare a measured value with the true value as a percentage.

How it works

Percent error = |measured - true| / |true| x 100. It shows how far a measurement is from the accepted value as a share of that value.

Frequently asked questions

Can percent error be negative?

The standard formula uses an absolute value, so it is never negative. The signed error shows direction.

What is a good percent error?

It depends on the field. In school labs, under 5% is usually considered good.
