Bits to Megabits Converter

Convert bits to megabits instantly. 1 bits = 1e-06 Mb.

How it works

To convert bits to megabits, multiply the number of bits by 1e-06. One bit equals 1e-06 megabits, and one megabit equals 1,000,000 bits. The table shows common values.

Bits to Megabits formula

Megabits = bits × 1e-06

Worked example: convert 12.5 bits to megabits. Multiply 12.5 × 1e-06 = 1.25e-05 Mb. To go the other way, multiply megabits by 1,000,000 (or divide by 1e-06).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
