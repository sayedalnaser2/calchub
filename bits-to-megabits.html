Bits to Megabits Converter (Both Ways)

Convert bits to megabits and megabits to bits instantly. 1 bit = 1e-06 Mb.

Type in any 1 field and the rest are calculated.

How it works

To convert bits to megabits, multiply the number of bits by 1e-06. To convert megabits to bits, multiply by 1,000,000 (or divide by 1e-06). Type a value in either box and the other updates, so this one page works in both directions.

Bits to Megabits formula

Megabits = bits × 1e-06

Worked example: convert 12.5 bits to megabits. Multiply 12.5 × 1e-06 = 1.25e-05 Mb. To go the other way, multiply megabits by 1,000,000 (or divide by 1e-06).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
