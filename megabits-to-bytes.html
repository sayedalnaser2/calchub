Megabits to Bytes Converter

Convert megabits to bytes instantly. 1 Mb = 125,000 B.

How it works

To convert megabits to bytes, multiply the number of megabits by 125,000. One megabit equals 125,000 bytes, and one byte equals 8e-06 megabits. The table shows common values.

Megabits to Bytes formula

Bytes = megabits × 125,000

Worked example: convert 12.5 megabits to bytes. Multiply 12.5 × 125,000 = 1,562,500 B. To go the other way, multiply bytes by 8e-06 (or divide by 125,000).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
