Bytes to Gibibytes Converter

Convert bytes to gibibytes instantly. 1 B = 9.31323e-10 GiB.

How it works

To convert bytes to gibibytes, multiply the number of bytes by 9.31323e-10. One byte equals 9.31323e-10 gibibytes, and one gibibyte equals 1,073,741,800 bytes. The table shows common values.

Bytes to Gibibytes formula

Gibibytes = bytes × 9.31323e-10

Worked example: convert 12.5 bytes to gibibytes. Multiply 12.5 × 9.31323e-10 = 1.16415e-08 GiB. To go the other way, multiply gibibytes by 1,073,741,800 (or divide by 9.31323e-10).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
