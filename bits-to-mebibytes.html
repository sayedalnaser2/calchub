Bits to Mebibytes Converter

Convert bits to mebibytes instantly. 1 bit = 1.19209e-07 MiB.

How it works

To convert bits to mebibytes, multiply the number of bits by 1.19209e-07. One bit equals 1.19209e-07 mebibytes, and one mebibyte equals 8,388,608 bits. The table shows common values.

Bits to Mebibytes formula

Mebibytes = bits × 1.19209e-07

Worked example: convert 12.5 bits to mebibytes. Multiply 12.5 × 1.19209e-07 = 1.49012e-06 MiB. To go the other way, multiply mebibytes by 8,388,608 (or divide by 1.19209e-07).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
