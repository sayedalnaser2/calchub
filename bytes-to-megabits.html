Bytes to Megabits Converter

Convert bytes to megabits instantly. 1 B = 8e-06 Mb.

How it works

To convert bytes to megabits, multiply the number of bytes by 8e-06. One byte equals 8e-06 megabits, and one megabit equals 125,000 bytes. The table shows common values.

Bytes to Megabits formula

Megabits = bytes × 8e-06

Worked example: convert 12.5 bytes to megabits. Multiply 12.5 × 8e-06 = 0.0001 Mb. To go the other way, multiply megabits by 125,000 (or divide by 8e-06).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
