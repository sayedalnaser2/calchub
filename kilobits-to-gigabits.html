How it works

To convert kilobits to gigabits, multiply the number of kilobits by 1e-06. To convert gigabits to kilobits, multiply by 1,000,000 (or divide by 1e-06). Type a value in either box and the other updates, so this one page works in both directions.

Kilobits to Gigabits formula

Gigabits = kilobits × 1e-06

Worked example: convert 12.5 kilobits to gigabits. Multiply 12.5 × 1e-06 = 1.25e-05 Gb. To go the other way, multiply gigabits by 1,000,000 (or divide by 1e-06).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
