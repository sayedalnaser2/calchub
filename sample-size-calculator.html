Sample Size Calculator

Find the number of respondents needed for a survey.

How it works

n = z² x p(1-p) / e², with a finite-population correction when the population is known. Using p = 50% gives the largest, safest sample.

Frequently asked questions

Does a bigger population need a much bigger sample?

No. Beyond a few thousand, the required sample barely changes.
