Petabytes to Bits Converter

Convert petabytes to bits instantly. 1 PB = 8e+15 bits.

How it works

To convert petabytes to bits, multiply the number of petabytes by 8e+15. One petabyte equals 8e+15 bits, and one bit equals 1.25e-16 petabytes. The table shows common values.

Petabytes to Bits formula

Bits = petabytes × 8e+15

Worked example: convert 12.5 petabytes to bits. Multiply 12.5 × 8e+15 = 1e+17 bits. To go the other way, multiply bits by 1.25e-16 (or divide by 8e+15).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.

There are 1.25e-16 petabytes in one bit.
