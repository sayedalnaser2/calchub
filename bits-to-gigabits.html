Bits to Gigabits Converter (Both Ways)

Convert bits to gigabits and gigabits to bits instantly. 1 bit = 1e-09 Gb.

How it works

To convert bits to gigabits, multiply the number of bits by 1e-09. To convert gigabits to bits, multiply by 1,000,000,000 (or divide by 1e-09). Type a value in either box and the other updates, so this one page works in both directions.

Bits to Gigabits formula

Gigabits = bits × 1e-09

Worked example: convert 12.5 bits to gigabits. Multiply 12.5 × 1e-09 = 1.25e-08 Gb. To go the other way, multiply gigabits by 1,000,000,000 (or divide by 1e-09).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
