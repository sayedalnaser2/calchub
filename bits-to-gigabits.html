Bits to Gigabits Converter

Convert bits to gigabits instantly. 1 bits = 1e-09 Gb.

How it works

To convert bits to gigabits, multiply the number of bits by 1e-09. One bit equals 1e-09 gigabits, and one gigabit equals 1,000,000,000 bits. The table shows common values.

Bits to Gigabits formula

Gigabits = bits × 1e-09

Worked example: convert 12.5 bits to gigabits. Multiply 12.5 × 1e-09 = 1.25e-08 Gb. To go the other way, multiply gigabits by 1,000,000,000 (or divide by 1e-09).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
