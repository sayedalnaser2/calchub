Bits to Megabytes Converter

Convert bits to megabytes instantly. 1 bits = 1.25e-07 MB.

How it works

To convert bits to megabytes, multiply the number of bits by 1.25e-07. One bit equals 1.25e-07 megabytes, and one megabyte equals 8,000,000 bits. The table shows common values.

Bits to Megabytes formula

Megabytes = bits × 1.25e-07

Worked example: convert 12.5 bits to megabytes. Multiply 12.5 × 1.25e-07 = 1.5625e-06 MB. To go the other way, multiply megabytes by 8,000,000 (or divide by 1.25e-07).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
