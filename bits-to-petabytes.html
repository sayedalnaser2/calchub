Bits to Petabytes Converter

Convert bits to petabytes instantly. 1 bits = 1.25e-16 PB.

How it works

To convert bits to petabytes, multiply the number of bits by 1.25e-16. One bit equals 1.25e-16 petabytes, and one petabyte equals 8e+15 bits. The table shows common values.

Bits to Petabytes formula

Petabytes = bits × 1.25e-16

Worked example: convert 12.5 bits to petabytes. Multiply 12.5 × 1.25e-16 = 1.5625e-15 PB. To go the other way, multiply petabytes by 8e+15 (or divide by 1.25e-16).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.

There are 8e+15 bits in one petabyte.
