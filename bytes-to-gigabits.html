Bytes to Gigabits Converter

Convert bytes to gigabits instantly. 1 B = 8e-09 Gb.

How it works

To convert bytes to gigabits, multiply the number of bytes by 8e-09. One byte equals 8e-09 gigabits, and one gigabit equals 125,000,000 bytes. The table shows common values.

Bytes to Gigabits formula

Gigabits = bytes × 8e-09

Worked example: convert 12.5 bytes to gigabits. Multiply 12.5 × 8e-09 = 1e-07 Gb. To go the other way, multiply gigabits by 125,000,000 (or divide by 8e-09).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
