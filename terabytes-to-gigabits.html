How it works

To convert terabytes to gigabits, multiply the number of terabytes by 8,000. To convert gigabits to terabytes, multiply by 0.000125 (or divide by 8,000). Type a value in either box and the other updates, so this one page works in both directions.

Terabytes to Gigabits formula

Gigabits = terabytes × 8,000

Worked example: convert 12.5 terabytes to gigabits. Multiply 12.5 × 8,000 = 100,000 Gb. To go the other way, multiply gigabits by 0.000125 (or divide by 8,000).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
