How it works

To convert petabytes to tebibytes, multiply the number of petabytes by 909.4947. One petabyte equals 909.4947 tebibytes, and one tebibyte equals 0.0010995116 petabytes. The table shows common values.

Petabytes to Tebibytes formula

Tebibytes = petabytes × 909.4947

Worked example: convert 12.5 petabytes to tebibytes. Multiply 12.5 × 909.4947 = 11,368.684 TiB. To go the other way, multiply tebibytes by 0.0010995116 (or divide by 909.4947).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
