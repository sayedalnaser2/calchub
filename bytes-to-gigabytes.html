How it works

To convert bytes to gigabytes, multiply the number of bytes by 1e-09. To convert gigabytes to bytes, multiply by 1,000,000,000 (or divide by 1e-09). Type a value in either box and the other updates, so this one page works in both directions.

Bytes to Gigabytes formula

Gigabytes = bytes × 1e-09

Worked example: convert 12.5 bytes to gigabytes. Multiply 12.5 × 1e-09 = 1.25e-08 GB. To go the other way, multiply gigabytes by 1,000,000,000 (or divide by 1e-09).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
