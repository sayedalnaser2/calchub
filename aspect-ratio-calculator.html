Aspect Ratio Calculator

Scale an image or screen: enter any three of the four dimensions and get the fourth.

Type in any 3 fields and the rest are calculated.

How it works

Divide width and height by their GCD for the ratio. To resize, keep the ratio and compute new height = new width x height / width.

Formula

Keeping the ratio width : height constant, new height = original height x new width / original width. Enter any three values.

Frequently asked questions

Common ratios?

16:9 for video, 4:3 for older screens, 3:2 for photos.
