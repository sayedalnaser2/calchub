Bits to Gigabytes Converter

Convert bits to gigabytes instantly. 1 bits = 1.25e-10 GB.

How it works

To convert bits to gigabytes, multiply the number of bits by 1.25e-10. One bit equals 1.25e-10 gigabytes, and one gigabyte equals 8,000,000,000 bits. The table shows common values.

Bits to Gigabytes formula

Gigabytes = bits × 1.25e-10

Worked example: convert 12.5 bits to gigabytes. Multiply 12.5 × 1.25e-10 = 1.5625e-09 GB. To go the other way, multiply gigabytes by 8,000,000,000 (or divide by 1.25e-10).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
