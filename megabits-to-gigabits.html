How it works

To convert megabits to gigabits, multiply the number of megabits by 0.001. To convert gigabits to megabits, multiply by 1,000 (or divide by 0.001). Type a value in either box and the other updates, so this one page works in both directions.

Megabits to Gigabits formula

Gigabits = megabits × 0.001

Worked example: convert 12.5 megabits to gigabits. Multiply 12.5 × 0.001 = 0.0125 Gb. To go the other way, multiply gigabits by 1,000 (or divide by 0.001).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
