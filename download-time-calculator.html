How it works

Time = file size in megabits / speed in Mbps. Real speeds are usually 5-20% lower due to overhead.

Formula

Time = file size / speed. Speeds in megabits per second are divided by 8 to give megabytes per second. Real downloads are usually 5-10% slower because of overhead.
