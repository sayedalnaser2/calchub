How it works

To convert kilobytes to gigabits, multiply the number of kilobytes by 8e-06. To convert gigabits to kilobytes, multiply by 125,000 (or divide by 8e-06). Type a value in either box and the other updates, so this one page works in both directions.

Kilobytes to Gigabits formula

Gigabits = kilobytes × 8e-06

Worked example: convert 12.5 kilobytes to gigabits. Multiply 12.5 × 8e-06 = 0.0001 Gb. To go the other way, multiply gigabits by 125,000 (or divide by 8e-06).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
