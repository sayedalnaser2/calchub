Bytes to Mebibytes Converter

Convert bytes to mebibytes instantly. 1 B = 9.53674e-07 MiB.

How it works

To convert bytes to mebibytes, multiply the number of bytes by 9.53674e-07. One byte equals 9.53674e-07 mebibytes, and one mebibyte equals 1,048,576 bytes. The table shows common values.

Bytes to Mebibytes formula

Mebibytes = bytes × 9.53674e-07

Worked example: convert 12.5 bytes to mebibytes. Multiply 12.5 × 9.53674e-07 = 1.19209e-05 MiB. To go the other way, multiply mebibytes by 1,048,576 (or divide by 9.53674e-07).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
