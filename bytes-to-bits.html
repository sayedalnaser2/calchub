Bytes to Bits Converter (Both Ways)

Convert bytes to bits and bits to bytes instantly. 1 B = 8 bits.

Type in any 1 field and the rest are calculated.

How it works

To convert bytes to bits, multiply the number of bytes by 8. To convert bits to bytes, multiply by 0.125 (or divide by 8). Type a value in either box and the other updates, so this one page works in both directions.

Bytes to Bits formula

Bits = bytes × 8

Worked example: convert 12.5 bytes to bits. Multiply 12.5 × 8 = 100 bits. To go the other way, multiply bits by 0.125 (or divide by 8).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.

Frequently asked questions

There are 0.125 bytes in one bit.
