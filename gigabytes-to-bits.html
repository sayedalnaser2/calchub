Gigabytes to Bits Converter

Convert gigabytes to bits instantly. 1 GB = 8,000,000,000 bits.

How it works

To convert gigabytes to bits, multiply the number of gigabytes by 8,000,000,000. One gigabyte equals 8,000,000,000 bits, and one bit equals 1.25e-10 gigabytes. The table shows common values.

Gigabytes to Bits formula

Bits = gigabytes × 8,000,000,000

Worked example: convert 12.5 gigabytes to bits. Multiply 12.5 × 8,000,000,000 = 100,000,000,000 bits. To go the other way, multiply bits by 1.25e-10 (or divide by 8,000,000,000).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
