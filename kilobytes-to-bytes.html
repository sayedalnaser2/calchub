Kilobytes to Bytes Converter

Convert kilobytes to bytes instantly. 1 KB = 1000 B.

How it works

To convert kilobytes to bytes, multiply the number of kilobytes by 1000. One kilobyte equals 1000 bytes, and one byte equals 0.001 kilobytes. The table shows common values.

Kilobytes to Bytes formula

Bytes = kilobytes × 1000

Worked example: convert 12.5 kilobytes to bytes. Multiply 12.5 × 1000 = 12500 B. To go the other way, multiply bytes by 0.001 (or divide by 1000).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
