How it works

To convert kilobytes to kibibytes, multiply the number of kilobytes by 0.9765625. To convert kibibytes to kilobytes, multiply by 1.024 (or divide by 0.9765625). Type a value in either box and the other updates, so this one page works in both directions.

Kilobytes to Kibibytes formula

Kibibytes = kilobytes × 0.9765625

Worked example: convert 12.5 kilobytes to kibibytes. Multiply 12.5 × 0.9765625 = 12.207031 KiB. To go the other way, multiply kibibytes by 1.024 (or divide by 0.9765625).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
