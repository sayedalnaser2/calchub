How it works

To convert megabytes to gigabytes, multiply the number of megabytes by 0.001. To convert gigabytes to megabytes, multiply by 1,000 (or divide by 0.001). Type a value in either box and the other updates, so this one page works in both directions.

Megabytes to Gigabytes formula

Gigabytes = megabytes × 0.001

Worked example: convert 12.5 megabytes to gigabytes. Multiply 12.5 × 0.001 = 0.0125 GB. To go the other way, multiply gigabytes by 1,000 (or divide by 0.001).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
