How it works

To convert bytes to kilobytes, multiply the number of bytes by 0.001. To convert kilobytes to bytes, multiply by 1,000 (or divide by 0.001). Type a value in either box and the other updates, so this one page works in both directions.

Bytes to Kilobytes formula

Kilobytes = bytes × 0.001

Worked example: convert 12.5 bytes to kilobytes. Multiply 12.5 × 0.001 = 0.0125 KB. To go the other way, multiply kilobytes by 1,000 (or divide by 0.001).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
