Rafter Length Calculator

Calculate common rafter length and cut angle from run and roof pitch.

How it works

Rafter length = run x sqrt(1 + (rise/12)^2). The overhang is added to the run before multiplying. Deduct half the ridge board thickness and add for any birdsmouth detail as your plans require.

Frequently asked questions

What is a 6/12 pitch?

The roof rises 6 inches for every 12 inches of horizontal run, about 26.57 degrees.

Is this the ridge length?

No, it is the length of one common rafter along the slope.
