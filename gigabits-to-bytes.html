Gigabits to Bytes Converter

Convert gigabits to bytes instantly. 1 Gb = 125,000,000 B.

How it works

To convert gigabits to bytes, multiply the number of gigabits by 125,000,000. One gigabit equals 125,000,000 bytes, and one byte equals 8e-09 gigabits. The table shows common values.

Gigabits to Bytes formula

Bytes = gigabits × 125,000,000

Worked example: convert 12.5 gigabits to bytes. Multiply 12.5 × 125,000,000 = 1,562,500,000 B. To go the other way, multiply bytes by 8e-09 (or divide by 125,000,000).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
