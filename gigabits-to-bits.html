Gigabits to Bits Converter

Convert gigabits to bits instantly. 1 Gb = 1,000,000,000 bits.

How it works

To convert gigabits to bits, multiply the number of gigabits by 1,000,000,000. One gigabit equals 1,000,000,000 bits, and one bit equals 1e-09 gigabits. The table shows common values.

Gigabits to Bits formula

Bits = gigabits × 1,000,000,000

Worked example: convert 12.5 gigabits to bits. Multiply 12.5 × 1,000,000,000 = 12,500,000,000 bits. To go the other way, multiply bits by 1e-09 (or divide by 1,000,000,000).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
