Terabytes to Bytes Converter

Convert terabytes to bytes instantly. 1 TB = 1e+12 B.

How it works

To convert terabytes to bytes, multiply the number of terabytes by 1e+12. One terabyte equals 1e+12 bytes, and one byte equals 1e-12 terabytes. The table shows common values.

Terabytes to Bytes formula

Bytes = terabytes × 1e+12

Worked example: convert 12.5 terabytes to bytes. Multiply 12.5 × 1e+12 = 1.25e+13 B. To go the other way, multiply bytes by 1e-12 (or divide by 1e+12).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
