Convert megabytes to terabytes and terabytes to megabytes instantly. 1 MB = 1e-06 TB.

How it works

To convert megabytes to terabytes, multiply the number of megabytes by 1e-06. To convert terabytes to megabytes, multiply by 1,000,000 (or divide by 1e-06). Type a value in either box and the other updates, so this one page works in both directions.

Megabytes to Terabytes formula

Terabytes = megabytes × 1e-06

Worked example: convert 12.5 megabytes to terabytes. Multiply 12.5 × 1e-06 = 1.25e-05 TB. To go the other way, multiply terabytes by 1,000,000 (or divide by 1e-06).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
