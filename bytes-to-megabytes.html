Bytes to Megabytes Converter

Convert bytes to megabytes instantly. 1 B = 1e-06 MB.

How it works

To convert bytes to megabytes, multiply the number of bytes by 1e-06. One byte equals 1e-06 megabytes, and one megabyte equals 1,000,000 bytes. The table shows common values.

Bytes to Megabytes formula

Megabytes = bytes × 1e-06

Worked example: convert 12.5 bytes to megabytes. Multiply 12.5 × 1e-06 = 1.25e-05 MB. To go the other way, multiply megabytes by 1,000,000 (or divide by 1e-06).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
