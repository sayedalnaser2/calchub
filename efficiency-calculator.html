Efficiency Calculator

Calculate efficiency as the ratio of useful output to input energy or power.

How it works

Efficiency = useful output / input x 100%. Use the same unit for both. The remainder is lost, typically as heat.

Frequently asked questions

Can efficiency exceed 100%?

No for a single device. Heat pumps report COP above 1, which is a different measure.

What is a typical motor efficiency?

Electric motors can reach 90% or more; gasoline engines about 25-35%.
