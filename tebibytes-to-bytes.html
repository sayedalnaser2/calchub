Tebibytes to Bytes Converter

Convert tebibytes to bytes instantly. 1 TiB = 1,099,511,600,000 B.

How it works

To convert tebibytes to bytes, multiply the number of tebibytes by 1,099,511,600,000. One tebibyte equals 1,099,511,600,000 bytes, and one byte equals 9.09495e-13 tebibytes. The table shows common values.

Tebibytes to Bytes formula

Bytes = tebibytes × 1,099,511,600,000

Worked example: convert 12.5 tebibytes to bytes. Multiply 12.5 × 1,099,511,600,000 = 13,743,895,000,000 B. To go the other way, multiply bytes by 9.09495e-13 (or divide by 1,099,511,600,000).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
