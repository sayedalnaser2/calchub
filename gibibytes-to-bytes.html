Gibibytes to Bytes Converter

Convert gibibytes to bytes instantly. 1 GiB = 1,073,741,800 B.

How it works

To convert gibibytes to bytes, multiply the number of gibibytes by 1,073,741,800. One gibibyte equals 1,073,741,800 bytes, and one byte equals 9.31323e-10 gibibytes. The table shows common values.

Gibibytes to Bytes formula

Bytes = gibibytes × 1,073,741,800

Worked example: convert 12.5 gibibytes to bytes. Multiply 12.5 × 1,073,741,800 = 13,421,773,000 B. To go the other way, multiply bytes by 9.31323e-10 (or divide by 1,073,741,800).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
