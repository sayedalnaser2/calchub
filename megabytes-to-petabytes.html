How it works

To convert megabytes to petabytes, multiply the number of megabytes by 1e-09. To convert petabytes to megabytes, multiply by 1,000,000,000 (or divide by 1e-09). Type a value in either box and the other updates, so this one page works in both directions.

Megabytes to Petabytes formula

Petabytes = megabytes × 1e-09

Worked example: convert 12.5 megabytes to petabytes. Multiply 12.5 × 1e-09 = 1.25e-08 PB. To go the other way, multiply petabytes by 1,000,000,000 (or divide by 1e-09).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
