Bytes to Terabytes Converter

Convert bytes to terabytes instantly. 1 B = 1e-12 TB.

How it works

To convert bytes to terabytes, multiply the number of bytes by 1e-12. One byte equals 1e-12 terabytes, and one terabyte equals 1e+12 bytes. The table shows common values.

Bytes to Terabytes formula

Terabytes = bytes × 1e-12

Worked example: convert 12.5 bytes to terabytes. Multiply 12.5 × 1e-12 = 1.25e-11 TB. To go the other way, multiply terabytes by 1e+12 (or divide by 1e-12).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
