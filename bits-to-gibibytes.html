Bits to Gibibytes Converter

Convert bits to gibibytes instantly. 1 bits = 1.16415e-10 GiB.

How it works

To convert bits to gibibytes, multiply the number of bits by 1.16415e-10. One bit equals 1.16415e-10 gibibytes, and one gibibyte equals 8,589,934,600 bits. The table shows common values.

Bits to Gibibytes formula

Gibibytes = bits × 1.16415e-10

Worked example: convert 12.5 bits to gibibytes. Multiply 12.5 × 1.16415e-10 = 1.45519e-09 GiB. To go the other way, multiply gibibytes by 8,589,934,600 (or divide by 1.16415e-10).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
