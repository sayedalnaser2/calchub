How it works

To convert gigabits to gibibytes, multiply the number of gigabits by 0.11641532. One gigabit equals 0.11641532 gibibytes, and one gibibyte equals 8.5899346 gigabits. The table shows common values.

Gigabits to Gibibytes formula

Gibibytes = gigabits × 0.11641532

Worked example: convert 12.5 gigabits to gibibytes. Multiply 12.5 × 0.11641532 = 1.4551915 GiB. To go the other way, multiply gibibytes by 8.5899346 (or divide by 0.11641532).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
