Terabytes to Bits Converter

Convert terabytes to bits instantly. 1 TB = 8,000,000,000,000 bits.

How it works

To convert terabytes to bits, multiply the number of terabytes by 8,000,000,000,000. One terabyte equals 8,000,000,000,000 bits, and one bit equals 1.25e-13 terabytes. The table shows common values.

Terabytes to Bits formula

Bits = terabytes × 8,000,000,000,000

Worked example: convert 12.5 terabytes to bits. Multiply 12.5 × 8,000,000,000,000 = 100,000,000,000,000 bits. To go the other way, multiply bits by 1.25e-13 (or divide by 8,000,000,000,000).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
