Mebibytes to Bytes Converter

Convert mebibytes to bytes instantly. 1 MiB = 1,048,576 B.

How it works

To convert mebibytes to bytes, multiply the number of mebibytes by 1,048,576. One mebibyte equals 1,048,576 bytes, and one byte equals 9.53674e-07 mebibytes. The table shows common values.

Mebibytes to Bytes formula

Bytes = mebibytes × 1,048,576

Worked example: convert 12.5 mebibytes to bytes. Multiply 12.5 × 1,048,576 = 13,107,200 B. To go the other way, multiply bytes by 9.53674e-07 (or divide by 1,048,576).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
