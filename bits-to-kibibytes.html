How it works

To convert bits to kibibytes, multiply the number of bits by 0.00012207031. To convert kibibytes to bits, multiply by 8,192 (or divide by 0.00012207031). Type a value in either box and the other updates, so this one page works in both directions.

Bits to Kibibytes formula

Kibibytes = bits × 0.00012207031

Worked example: convert 12.5 bits to kibibytes. Multiply 12.5 × 0.00012207031 = 0.0015258789 KiB. To go the other way, multiply kibibytes by 8,192 (or divide by 0.00012207031).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
