How it works

To convert terabytes to kibibytes, multiply the number of terabytes by 976,562,500. To convert kibibytes to terabytes, multiply by 1.024e-09 (or divide by 976,562,500). Type a value in either box and the other updates, so this one page works in both directions.

Terabytes to Kibibytes formula

Kibibytes = terabytes × 976,562,500

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
