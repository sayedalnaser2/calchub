Bytes to Kilobits Converter

Convert bytes to kilobits instantly. 1 B = 0.008 Kb.

How it works

To convert bytes to kilobits, multiply the number of bytes by 0.008. One byte equals 0.008 kilobits, and one kilobit equals 125 bytes. The table shows common values.

Bytes to Kilobits formula

Kilobits = bytes × 0.008

Worked example: convert 12.5 bytes to kilobits. Multiply 12.5 × 0.008 = 0.1 Kb. To go the other way, multiply kilobits by 125 (or divide by 0.008).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
