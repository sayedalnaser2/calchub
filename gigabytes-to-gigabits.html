How it works

To convert gigabytes to gigabits, multiply the number of gigabytes by 8. To convert gigabits to gigabytes, multiply by 0.125 (or divide by 8). Type a value in either box and the other updates, so this one page works in both directions.

Gigabytes to Gigabits formula

Gigabits = gigabytes × 8

Worked example: convert 12.5 gigabytes to gigabits. Multiply 12.5 × 8 = 100 Gb. To go the other way, multiply gigabits by 0.125 (or divide by 8).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
