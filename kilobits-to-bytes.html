Kilobits to Bytes Converter

Convert kilobits to bytes instantly. 1 Kb = 125 B.

How it works

To convert kilobits to bytes, multiply the number of kilobits by 125. One kilobit equals 125 bytes, and one byte equals 0.008 kilobits. The table shows common values.

Kilobits to Bytes formula

Bytes = kilobits × 125

Worked example: convert 12.5 kilobits to bytes. Multiply 12.5 × 125 = 1,562.5 B. To go the other way, multiply bytes by 0.008 (or divide by 125).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
