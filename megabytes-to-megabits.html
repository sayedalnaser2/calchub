How it works

To convert megabytes to megabits, multiply the number of megabytes by 8. To convert megabits to megabytes, multiply by 0.125 (or divide by 8). Type a value in either box and the other updates, so this one page works in both directions.

Megabytes to Megabits formula

Megabits = megabytes × 8

Worked example: convert 12.5 megabytes to megabits. Multiply 12.5 × 8 = 100 Mb. To go the other way, multiply megabits by 0.125 (or divide by 8).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
