Kibibytes to Bits Converter

Convert kibibytes to bits instantly. 1 KiB = 8,192 bits.

How it works

To convert kibibytes to bits, multiply the number of kibibytes by 8,192. One kibibyte equals 8,192 bits, and one bit equals 0.00012207031 kibibytes. The table shows common values.

Kibibytes to Bits formula

Bits = kibibytes × 8,192

Worked example: convert 12.5 kibibytes to bits. Multiply 12.5 × 8,192 = 102,400 bits. To go the other way, multiply bits by 0.00012207031 (or divide by 8,192).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
