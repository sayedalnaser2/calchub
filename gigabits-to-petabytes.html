How it works

To convert gigabits to petabytes, multiply the number of gigabits by 1.25e-07. To convert petabytes to gigabits, multiply by 8,000,000 (or divide by 1.25e-07). Type a value in either box and the other updates, so this one page works in both directions.

Gigabits to Petabytes formula

Petabytes = gigabits × 1.25e-07

Worked example: convert 12.5 gigabits to petabytes. Multiply 12.5 × 1.25e-07 = 1.5625e-06 PB. To go the other way, multiply petabytes by 8,000,000 (or divide by 1.25e-07).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
