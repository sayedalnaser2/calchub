Nth Root Calculator

Calculate the square root, cube root or any nth root of a number.

How it works

The nth root of x is x raised to the power 1/n. Odd roots of negative numbers are real (for example the cube root of -8 is -2), while even roots of negatives are not.

Frequently asked questions

What is the cube root of 27?

3, because 3 x 3 x 3 = 27.

Is a root the same as a fractional exponent?

Yes: the nth root of x equals x^(1/n).
