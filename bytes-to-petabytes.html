Bytes to Petabytes Converter

Convert bytes to petabytes instantly. 1 B = 1e-15 PB.

How it works

To convert bytes to petabytes, multiply the number of bytes by 1e-15. One byte equals 1e-15 petabytes, and one petabyte equals 1,000,000,000,000,000 bytes. The table shows common values.

Bytes to Petabytes formula

Petabytes = bytes × 1e-15

Worked example: convert 12.5 bytes to petabytes. Multiply 12.5 × 1e-15 = 1.25e-14 PB. To go the other way, multiply petabytes by 1,000,000,000,000,000 (or divide by 1e-15).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
