Convert kibibytes to mebibytes instantly. 1 KiB = 0.0009765625 MiB.

How it works

To convert kibibytes to mebibytes, multiply the number of kibibytes by 0.0009765625. One kibibyte equals 0.0009765625 mebibytes, and one mebibyte equals 1,024 kibibytes. The table shows common values.

Kibibytes to Mebibytes formula

Mebibytes = kibibytes × 0.0009765625

Worked example: convert 12.5 kibibytes to mebibytes. Multiply 12.5 × 0.0009765625 = 0.012207031 MiB. To go the other way, multiply mebibytes by 1,024 (or divide by 0.0009765625).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
