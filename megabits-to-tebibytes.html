How it works

To convert megabits to tebibytes, multiply the number of megabits by 1.13687e-07. To convert tebibytes to megabits, multiply by 8,796,093 (or divide by 1.13687e-07). Type a value in either box and the other updates, so this one page works in both directions.

Megabits to Tebibytes formula

Tebibytes = megabits × 1.13687e-07

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
