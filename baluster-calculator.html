Baluster Spacing Calculator

Find how many balusters you need for a railing and the exact gap between them.

How it works

Balusters n satisfy length = n x width + (n + 1) x gap, so n = ceil((length - gap) / (width + gap)). Most building codes require that a 4-inch sphere cannot pass through the railing.

Frequently asked questions

What is the 4-inch rule?

Gaps between balusters must be small enough that a 4-inch sphere cannot pass.

Do I count the end gaps?

Yes, the formula includes a gap at each end next to the posts.
