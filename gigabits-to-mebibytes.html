How it works

To convert gigabits to mebibytes, multiply the number of gigabits by 119.20929. To convert mebibytes to gigabits, multiply by 0.008388608 (or divide by 119.20929). Type a value in either box and the other updates, so this one page works in both directions.

Gigabits to Mebibytes formula

Mebibytes = gigabits × 119.20929

Worked example: convert 12.5 gigabits to mebibytes. Multiply 12.5 × 119.20929 = 1,490.1161 MiB. To go the other way, multiply mebibytes by 0.008388608 (or divide by 119.20929).

About digital storage units

These conversions use decimal (SI) prefixes where 1 KB = 1,000 bytes. Some operating systems use binary multiples of 1,024 instead, so reported sizes can differ slightly.
